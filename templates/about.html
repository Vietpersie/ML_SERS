Giới thiệu dự án

ML-SERS Analyzer là nền tảng web kết hợp phương pháp quang phổ Surface-Enhanced Raman Scattering (SERS) với các thuật toán Machine Learning để hỗ trợ phân tích và phân loại mẫu trong nghiên cứu khoa học.

Công nghệ sử dụng
  • Flask — Backend framework
  • Plotly — Biểu đồ phổ SERS tương tác
  • scikit-learn — PCA, PLS-DA, SVM, phân loại mẫu
  • pandas / numpy — Xử lý dữ liệu
